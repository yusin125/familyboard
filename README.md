# 패밀리보드 (FamilyBoard)

바쁜 가족 구성원 전체의 한 주 일정을 한 화면에서 비교해서 볼 수 있는 가족 주간 스케줄러입니다.
(팀 "바이브 Go" — 이번 버전은 "스케줄러" 기능만 포함합니다.)

## 특징

- PC(관리자 모드), 휴대폰/태블릿(뷰어 모드), 거실 TV(뷰어 모드 확대 표시) 등 **같은 Wi-Fi에 연결된 여러 기기**에서 동시에 같은 일정을 볼 수 있습니다.
- 일정 데이터는 브라우저가 아니라 **로컬 서버의 `data.json` 파일**에 저장되어 기기 간 동기화가 보장됩니다.
- 뷰어 화면은 8초마다 서버에서 최신 데이터를 자동으로 다시 불러옵니다 (polling).

## 실행 방법

```bash
npm install
npm start
```

서버가 실행되면 콘솔에 아래와 같은 접속 주소가 출력됩니다.

```
- 이 PC에서 접속:  http://localhost:3000
- 같은 와이파이의 다른 기기(휴대폰/태블릿/TV)에서 접속하려면:
    http://192.168.0.5:3000   (예시 - 실제 출력되는 IP를 사용하세요)
```

1. 이 명령을 실행한 PC에서 `http://localhost:3000` 으로 접속하면 관리자 모드로 전환해 일정을 입력/수정할 수 있습니다.
2. 같은 Wi-Fi에 연결된 휴대폰, 태블릿, 거실 TV의 브라우저에서 콘솔에 출력된 `http://[PC의 로컬IP]:3000` 주소로 접속하면 동일한 일정을 조회 전용(뷰어 모드)으로 볼 수 있습니다.
3. PC 방화벽에서 Node.js(포트 3000)에 대한 접속을 허용해야 다른 기기에서 접속이 가능할 수 있습니다.

## 화면 상단 모드 전환

화면 우측 상단의 "관리자 모드로 전환 / 뷰어 모드로 전환" 버튼으로 별도 로그인 없이 모드를 바꿀 수 있습니다.

- **관리자 모드**: 빈 시간대 클릭 시 일정 등록, 기존 일정 블록 클릭 시 수정/삭제, 좌측 사이드바에서 구성원 추가/이름 변경/색상 변경/삭제 가능
- **뷰어 모드**: 조회 전용 (입력/수정 불가), 모바일/태블릿/TV에서 사용

## 데이터 구조 (`data.json`)

서버 실행 시 예시 구성원 4명과 일정, 그리고 코드 내 로컬 데이터로 등록된 공휴일이 바로 표시됩니다.

```json
{
  "members": [{ "id": "...", "name": "아빠", "color": "#E3A542" }],
  "schedules": [
    { "id": "...", "memberId": "...", "date": "2026-08-10", "start": "09:00", "end": "18:00", "title": "회사 출근", "memo": "" }
  ]
}
```

## API

| Method | Path | 설명 |
|---|---|---|
| GET | /api/members | 구성원 전체 조회 |
| POST | /api/members | 구성원 등록 `{ name, color? }` |
| PUT | /api/members/:id | 구성원 수정 `{ name?, color? }` |
| DELETE | /api/members/:id | 구성원 삭제 (해당 구성원의 일정도 함께 삭제) |
| GET | /api/schedules | 일정 전체 조회 |
| POST | /api/schedules | 일정 등록 `{ memberId, date, start, end, title, memo? }` |
| PUT | /api/schedules/:id | 일정 수정 |
| DELETE | /api/schedules/:id | 일정 삭제 |

## 이번 범위에서 제외된 기능

일정 반복 등록, 모바일/태블릿에서의 일정 입력·수정, 월간 캘린더 직접 편집, 공휴일 외부 API 연동, 로그인/회원가입, 웹소켓 실시간 동기화는 이번 스케줄러 범위에 포함되지 않습니다.
